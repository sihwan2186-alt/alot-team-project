# S1 개인 추천과 S5 가상 제어 개발

현재 개인 조건별 학습·시뮬레이션은 [김시환 개인 모델](../김시환_개인모델/README.md)에 있다. 이 폴더의 가상 120실·규칙 정답 CART는 이전 검증 프로토타입으로 보존한다.

이전 `내일검토_S1_S5` 폴더를 내용 단위로 보존해 이동했습니다. 공통시뮬레이터 v0.2와 별도의 프로토타입이며 서로의 검증 수치로 대체하지 않습니다.

프로젝트 루트에서 기존 자동 검사를 실행합니다. 이 명령은 기존 결과 파일을 재생성하지 않고 테스트의 임시 폴더를 사용합니다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s "03_팀프로젝트/S1_S5" -p "test_*.py"
```

2026-11-03 정리 후 위 명령의 24개 테스트가 통과했습니다. AI가 수행한 점검이며 본인의 실습·캡처 증거와 구분합니다.

전체 결과를 새로 만들려면 다음을 실행합니다. 시뮬레이션_결과 폴더의 기존 생성 결과가 갱신됩니다.

```powershell
.\.venv\Scripts\python.exe "03_팀프로젝트/S1_S5/run_system.py"
```

현재 입력 스냅샷은 형제 폴더 `이전모의검증/synthetic_snapshot.csv`에서 읽습니다. 이번 정리에서 해당 상대 경로를 수정했습니다. 과거 발표·시나리오·결과 설명 파일은 당시 기록으로 보존했습니다.
