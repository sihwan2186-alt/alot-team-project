# 생성 모델과 단위

## 시계·점유·예약
기본 구간은 2026-09-01 00:00부터 2026-09-30 23:59까지다. Asia/Seoul의 `+09:00`을 포함한다. 기본 시드는 20261102. 별도 시작일·기간·간격도 지원한다. 내부 계산은 항상 1분이며 `step_minutes`는 출력 샘플링/에너지 적산 간격이다. 1440의 양의 약수여야 한다. `*_1min` 경로는 인터페이스 호환을 위해 유지되므로 비기본 간격은 manifest를 반드시 확인한다.

예약은 공간별로 운영시간 안에 생성한다. 평일·주말·시간대별 수요와 30/60/90/120분 길이를 적용하며 다음 예약은 이전 종료 이후에만 생성한다. 취소·노쇼 예약은 실제 점유를 만들지 않는다. 실제 도착은 0–10분 지연될 수 있고 실제 인원은 예약 인원보다 적을 수 있다. 빈 시간의 소규모 walk-in 변화는 이전 인원에 ±1/±2명 이벤트를 적용한다. 운영시간 종료 시 전원 퇴실한다. 정원으로 제한한 변화량을 기록하므로 입퇴실 이벤트 누적으로 인원을 재구성할 수 있다.

## 외기
외기 온도는 일별 고정 난수 편차 + 일주기 사인파다. 습도와 주야 소음, 06–18시 자연광 인자를 함께 만든다. 실제 2026년 9월 기상 관측 자료가 아니다. 같은 시간에 모든 공간은 같은 외기에 노출되지만 프로필의 자연광·열응답·부피에 따라 반응이 달라진다.

## CO₂
C는 ppm, V는 m³, G는 m³/person/hour, n은 인원, a는 ACH(hour⁻¹), Δt는 분이다.

`dC/d(hour) = n×G×10⁶/V + a×(C_out−C)`

상수 구간에서 다음 해석해를 쓴다.

`C_next = C_out + (C−C_out) exp(−aΔt/60) + (nG10⁶/V) (1−exp(−aΔt/60))/a`

`expm1`을 사용해 작은 환기 계수에서 반올림 손실을 줄인다. a≈0이면 발생량을 선형 적분한다. 실내를 완전 혼합한 단일 구획으로 가정하며 문·창문·복도 사이 이동은 모델링하지 않는다.

## 온도와 현열 수지 v0.2.0
`C_eff dT/ds = (UA_env + UA_vent)(T_out − T) + Q_people + Q_other + Q_HVAC`

C_eff는 kJ/K, UA는 kW/K, Q는 kW, 시간 s는 초다. `C_eff=area×120+ρ×volume×c_p`, `UA_env=area×3/1000`, `UA_vent=ρ×volume×c_p×ACH/3600`이다. 120 kJ/(m²·K)는 공기를 제외한 벽·가구 등의 유효 축열 가정이고 공기 열용량은 따로 더한다. 3 W/(m²·K)는 바닥 면적당 종합 외피 열교환 가정이며 실제 벽체 U값이 아니다. 일사 열획득과 다중 벽체 노드를 분해하지 않는다.

`Q_people=n×75/1000`, `Q_other=area×2/1000+P_lighting×lighting_level+P_standby`.
`P_HVAC=profile.hvac_power_kw×facility.hvac_power_fraction`, `Q_HVAC=−3.2×P_HVAC`(냉방), `+3.0×P_HVAC`(난방). HVAC가 꺼져 있거나 mode=off이면 전력과 공급 열량은 모두 0이다. 에너지 출력과 온도 모델은 같은 전력 함수를 사용한다. 고장 마스킹 이후 실제 설비 상태로 계산한다.

1분 동안 외기·인원·설비가 일정하다고 두고 `T_eq=T_out+Q_fixed/UA`, `T_next=T_eq+(T−T_eq)exp(−UA×60/C_eff)`를 해석적으로 적분한다. UA=0이면 선형 해를 사용한다. 작은 수의 차이는 expm1로 계산한다. **온도를 정상 범위로 강제 제한하지 않는다.** 구간 평균 온도로 외피·환기 열교환을 적분하고 `ΔE_stored=C_eff×ΔT/3600`와 열유입 합을 비교한다. 외기·열유속·COP·잔차를 `truth/thermal_balance_1min`에 매분 기록한다.

모든 계수는 `configs/environment_rules.toml [thermal]`에 있다. 유효 열용량 120, 종합 UA 3, 인체 현열 75 W, 냉방 COP 3.2·난방 COP 3.0, 기타 발열 2 W/m², 공기 밀도 1.2 kg/m³·비열 1.006 kJ/(kg·K), 조명·대기전력 실내 발열 분율 1.0은 초기 설계 가정이다. 학교 실측값·장비 인증 성능·문헌으로 확정된 최적 계수가 아니다. COP는 외기·부하·제습에 따라 변하지 않는다. 열수지 검증 범위는 **현열**이며 습도 모델의 제습·응축 잠열은 연결하지 않는다.

## 습도
수증기 밀도 A(g/m³)를 내부 상태로 유지한다. 외기와 지수적 혼합 + 인원 수분 발생량/V를 반영하고 냉방 시 제습 인자를 적용한다. 포화 수증기 밀도는 온도의 경험식으로 구하고 `RH=100×A/A_sat(T)`로 환산한다. 포화 초과는 응축으로 제거해 0–100%를 유지한다. 습도를 온도와 독립적인 균등 난수로 생성하지 않는다.

## 조도와 소음
`lux = daylight_lux×daylight_factor×exposure + lighting_lux×lighting_level`.

기본 소음, 외부 소음 감쇠, 인원·공간별 활동 강도, 설비 소음을 독립 소음원으로 근사한다. `L_total=10 log10 Σ10^(L_i/10)`. 매분 독립된 무작위 dB를 생성하지 않는다.

## 센서·이상
정답값에 센서별 정규 잡음을 더하고 분해능에 맞춰 양자화한다. 인원 센서는 기본적으로 정확하다. CO₂ 채널에 missing/spike/stuck/bias 고장을 주입하며 실제 CO₂를 바꾸지 않는다. 설비 고장과 고밀도 이용은 실제 환경에 영향을 준다. 한 공간에 동시에 하나의 주입 이상만 활성화한다. 고장 발생 확률은 공간·분당이며 지속시간과 유형 가중치는 TOML로 설정한다. 주입 원인은 기존 anomaly_events에 보존한다. v0.2에서는 fault_events, environment_status, environment_anomaly_events, recovery_events를 별도로 생성한다. 정의는 v0.2 변경 기록을 따른다.

## 제어와 에너지
관측값과 현재 점유로 HVAC·환기·조명을 제어한다. HVAC와 환기는 ON/OFF 기준을 달리하고 최소 상태 유지 시간을 적용한다. 결측 채널은 해당 제어 판단을 유지한다. 현재 점유가 0이면 설비 정지를 요청한다. `control_actions`는 변경 요청이며 고장 기간의 실제 상태는 `facility_states`를 확인한다. 현재 t에서 결정한 제어는 다음 구간 설비에 적용된다. 환경 truth(t)는 직전 구간 누적 결과이므로 새로운 명령의 관측 효과는 그 구간이 지난 뒤 확인한다.

`P_total=P_hvac+P_ventilation+P_lighting+P_standby` (kW).

`E_interval=Σ P_minute /60` (kWh). 출력 간격이 N분이면 N분 실제 에너지를 합산하고 전력은 평균한다. HVAC는 정격×가정 부하율, 환기·조명은 정격×수준으로 근사한다. COP는 온도 모델에 상수로 적용한다. 비선형 부분부하·외기별 성능곡선·실제 전기요금은 모델링하지 않는다. enable_energy_model=false는 에너지 CSV 출력을 0으로 만드는 기존 진단 옵션이며 물리 설비를 끄지 않는다. 이때 thermal_balance의 실제 전력은 남고 에너지 CSV와 대조하지 않는다. 에너지 분석용 데이터는 반드시 true로 생성한다.

## 집계
기본 5분 창은 [09:00,09:05), 즉 09:00–09:04 표본이다. 온습도·CO₂·조도 평균, CO₂ 최댓값/마지막값, 마지막 인원/최대 인원, 변수별 결측률, 관측 표본 수를 저장한다. 마지막값은 마지막 시점 결측이면 빈 값이다. 결측 표본은 평균·Leq에서 제외하고 모두 결측이면 빈 값이다. `Leq=10 log10(mean(10^(L/10)))`이며 dB 산술평균을 사용하지 않는다. 유효 표본에 대한 Leq이므로 결측률과 함께 해석한다. 에너지는 구간 합, 전력은 평균이다.
