> v0.2.0에서는 [모델 변경과 사용 안내](v0.2.0_release.md)가 우선합니다. 이 문서의 기존 실행 통계는 별도 표기가 없으면 v0.1.0 기준선입니다. 추가된 truth 파일·회복 레이블·검증 결과는 변경 안내와 deliverables/v0.2.0을 확인하세요.


## 사용자 제공 정보
호실 목록은 개발 지시서에 명시된 63개를 사용한다. 건물별 STU 38, LIB 12, WON 9, HEA 4이다. 원본 스크린샷 자체를 이 작업에서 다시 판독한 것은 아니다. 기존 `Project/rooms.csv`와 `Project/room_profiles.csv`는 읽기만 했고 수정하지 않았다. 새 프로필은 요구된 최신 범위에 맞춰 별도로 생성했다.

출처 URL: https://sisul.sunmoon.ac.kr/Page/Facilities/Apply_list.aspx?sgubun=H
공개 페이지는 소규모 스터디룸 시설예약 메뉴임을 확인했으나, 검색 결과에 전체 호실이 노출되지 않아 63개를 독립적으로 재검증한 것은 아니다. 호실 목록의 기준은 사용자 제공 자료다. `source_checked_date=2026-11-02`는 요청된 자료 기준일이며 웹 독립 검증 완료일을 뜻하지 않는다.

프로젝트 ID는 공식 시설 코드가 아니다. 층수는 B 접두사 또는 첫 자리에서 추정하며 `floor_verified=false`다.

## 모든 가상 프로필
정원, 면적, 높이, 운영시간, 모든 시설 존재 여부, 환기 ACH, 전력, 기본 소음, 열응답 및 자연광 계수는 합성 가정이다. 공식 건축 면적·법적 정원·공인 권장치·실제 학교 시설 사양으로 사용하면 안 된다.

유형 배정은 정렬한 ID를 고정 시드로 섞어 SMALL 25, MEDIUM 28, LARGE 10개로 고정한다. STU-B102A는 SMALL/6명/17㎡/09:00–21:00 예외다. 큰 정원 후보는 해당 유형의 큰 면적 대역에 배정한다. 부피는 면적×높이다. 상세 범위와 시설 보유 확률은 `configs/room_profile_rules.toml`에서 확인한다.

프로필 파일이 존재하면 다시 생성하지 않는다. 규칙을 변경해 재생성하려면 먼저 기존 파일을 별도 이름으로 백업하고 버전·이유를 이 문서에 추가한다. 실행 시 프로필을 자동 변경하지 않는다. 운영시간 재설정은 프로필 최초 생성 전 `[overrides."ROOM-ID"]` 테이블에서 정의한다. 이미 생성된 프로필에는 자동 소급 반영하지 않는다.

## 모델 계수와 제어 기준
환경·점유·고장·설비 TOML의 수치는 모두 설명 가능한 합성 예시를 위한 가정이다. 0.018 m³/person/hour CO₂ 발생량, 분당 수분량, HVAC 온도 변화량, 환기 임계값 및 센서 잡음도 실측 보정되지 않았다. 안전·쾌적·보건 기준으로 제시하지 않는다.

고밀도 이상은 운영시간 내 정원 100% 이용으로 정의한다. 정원 초과는 만들지 않는다. 예약 생성 시 취소가 확정된 모델이며 이후 취소 상태 변경 이력은 구현하지 않는다. 노쇼는 시뮬레이션 평가용 사후 특성이므로 실제 예측 입력에 사용하지 않는다.
