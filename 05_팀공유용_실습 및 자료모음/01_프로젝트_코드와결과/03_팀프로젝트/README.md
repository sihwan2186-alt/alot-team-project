# 팀 공통 프로젝트

현재 김시환의 개인 작업은 [개인 조건별 S1·S5 모델](김시환_개인모델/README.md)에서 확인한다. 기존 S1_S5 프로토타입과 새 미래 예측 모델의 데이터·정답·평가 범위를 구분한다.

| 폴더 | 내용 |
|---|---|
| 공통시뮬레이터 | 추가 ZIP의 v0.2 소스·설정·63실 마스터·실행 데이터·검증 근거 |
| S1_S5 | 기존 개인 추천·가상 제어 개발과 결과, 공통 v0.2 시뮬레이터와 별도 구현 |
| 이전모의검증 | 이전 시나리오 모의 검증 기록 |
| 문서 | 기술 백서 DOCX |
| 원본압축 | 받은 ZIP 보존본 |

Windows에서는 프로젝트 루트의 `시뮬레이터실행.ps1`을 사용합니다. 원본의 macOS .venv와 심볼릭 링크 파일은 Windows에서 사용할 수 없어 정리했습니다. 공통시뮬레이터/README.md의 원본 실행 기록·통계는 제공 자료의 기록이며 이번 사용자의 재실행 결과가 아닙니다.

```powershell
.\시뮬레이터실행.ps1 --help
```

v02-full-30d와 구버전 full-30d는 다른 열 모델의 비교 근거입니다. 둘 다 보존하고 truth를 일반 모델 입력과 합치지 않습니다. W10은 v02-full-30d의 하루치만 활용합니다. 프로젝트 내부 room_id는 공식 시설 코드가 아닙니다.
