김시환(2022451032)의 담당인 S1·S5를 별도로 구성했다. S5는 김정훈과의 공동 담당 범위다. 이전의 임의 가상 120실 CART나 교재의 재실 예측을 개인 만족도 모델로 사용하지 않는다. 모든 수치는 합성 데이터와 AI 실행 결과다.

## 개인 조건과 사용 범위

p=2·q=3으로 분석 시작은 10:00, 집계/예측 창은 8분, 환기 켜기 890ppm·해제 850ppm이다. 사용자가 유지한 설계 선호는 목표 온도 23℃·습도 50%, 조도≥300lux·소음≤45dB(A)·CO₂<890ppm이다. 기존 허용 범위 온도20~26℃·습도40~60%와 profile.json의 설계 가중치를 사용한다. 실제 만족도·선택 정답은 없다. q mod 3=0의 결함명은 원문 정의가 없어 추정하지 않았다.

| 구분 | S1 | S5 |
|---|---|---|
| 목적 | 다음 8분 창의 설정 선호 점수 예측 | 정확히 t+8분의 관측 CO₂ 예측 |
| 데이터 | v0.2 공통 입력의 63실·10시 이후 센서 | 개인 890/850 제어 기준선을 생성한 고정 대표 4실 |
| 특징 | 온습도·CO₂·조도·소음 Leq·재실·가상 정원·과거 변화·시각 | CO₂ 이력·재실·현재 환기·가상 부피/ACH·시각 |
| 제외 | 사용자 만족도 정답을 가정하지 않음 | 미래 인원·미래 설비·고장 정답·회복 종료·truth 입력 금지 |
| 평가 | 점수 MAE와 현재 유효 후보 안의 점수 후회 | ppm MAE·미래 초과 부가 지표·별도 환경/전력 시뮬레이션 |

S1은 원시 분 관측을 8분씩 집계하고 완료된 뒤 사용한다. 소음은 dB 산술평균 대신 에너지 기반 Leq를 계산한다. S5는 과거 8분을 문맥으로 쓸 수 있으나 학습 시점은 10시 이후로 제한한다. 8분 목표가 운영 종료나 분할 경계를 넘으면 제외한다.

학습·평가 표와 실제 추론 입력을 분리했다. 평가에는 유효한 미래 정답이 필요하지만, 추론 후보는 현재 관측만으로 정한다. 미래 정답이 결측이라는 이유로 현재 후보를 숨기지 않는다. `S1_inference_inputs.csv.gz`, `S5_inference_inputs.csv.gz`에는 실제 미래 정답 열이 없다. 현재 조건을 통과해도 미래의 모든 조건 충족이나 예약 가능성을 보장하는 것은 아니다.

9/1~21은 train, 22~25는 validation, 26~30은 test다. 무작위 혼합·test 선택·train+validation 재학습을 하지 않았다. 지속값, train에서만 대체/표준화하는 Ridge, 별도 표준화가 필요 없는 HistGradientBoosting 회귀를 비교했다. 검증 MAE가 지속값보다 최소 1% 개선될 때만 복잡한 모델을 고른다.

## 확인한 결과와 보류 조건

- S1 학습/검증/시험 106,388 / 20,305 / 25,320행. HGB 시험 MAE 2.988점, 지속값 4.006점. 실제 만족도 오차가 아니다.
- S5 학습/검증/시험 6,845 / 1,308 / 1,634행. HGB 시험 MAE 19.126ppm, 지속값 33.288ppm. 대표 4실의 미래 시간 평가이며 다른 59실의 제어 성능은 미확인이다.
- S1 시험 405시점 중 모든 조건을 만족하는 후보가 있는 시점은 6개다. 특히 습도 범위 이탈이 많다. 조건을 완화하거나 좋은 행만 뽑아 성능을 높이지 않았다. 추천 운영 적용은 보류하고 습도·기상·제습 가정 및 실제 선호 자료를 점검해야 한다.
- S5의 낮은 회귀 오차만으로 제어 개선을 주장하지 않는다. 같은 seed·예약·인원·고장에서 개인 규칙과 예측 보조 정책의 CO₂·전력을 별도로 비교한다.
- 기존 보고서의 192행/1764행 F1은 다른 입력·정답의 이상 감지/전송 검증이다. 이 미래 개인 모델 성능과 혼합하지 않는다.

## 실행과 결과 파일

프로젝트 루트 PowerShell에서 `실습시작.ps1`을 실행한다. 개인 모델의 읽기 전용 학생·관리자 화면이며 미래 실제 정답은 표시하지 않는다. 교재 W10 연습은 `실습시작.ps1 -Textbook`으로 별도 실행한다.

| 경로 | 내용 |
|---|---|
| profile.json | 확인된 개인 조건·분할·고정 대표 공간 |
| results/data_contract.json | 모델별 열 허용 목록·목표·기간·원본 해시 |
| results/S1_dataset.csv.gz, S5_dataset.csv.gz | 실제 선택된 학습 표 |
| results/S1_evaluation.json, S5_evaluation.json | 기준선·Ridge·HGB 비교 |
| results/S1_model.joblib, S5_model.joblib | 동결된 로컬 학습 모델 |
| results/model_review.json | 조건별 제외 건수·데이터 적합성 |
| results/S1_inference_inputs.csv.gz, S5_inference_inputs.csv.gz | 미래 정답 존재 여부와 무관한 현재 추론 입력 |
| results/S1_latest_results.json, S5_latest_results.json | 팀 공통 시나리오·공간·시각·단위 계약의 결과 JSON |
| results/paired_simulation_comparison.json | 별도 폐루프 제어 비교 |
| simulations | 개인 기준선과 예측 보조의 상태·환경·전력·검증 |
| diagnostics | 프로토콜 수정 전 결과, 최종 평가에서 제외 |

현재 결과는 동결 증거이므로 재학습·시뮬레이션으로 자동 덮어쓰지 않는다. 새 실험은 버전 작업 사본에서 개인 기준선 생성 → S1 입력/학습 → 개인 기준선의 S5 입력/학습 → 시험 기간만 예측 보조 적용 → 결과 검토 순서로 재현한다. 구현은 build_datasets.py, train_models.py, simulate_personal.py에 있다.

공통 엔진은 선택적 observation-only callback을 추가하고 기본 동작을 보존했다. 내부 환경 truth나 고장 객체를 정책에 전달하지 않는다. JSON 읽기에 UTF-8을 명시해 Windows 한글 설정 오류를 수정했다. 최소 가동시간은 설비 규칙의 5분이며 개인 8분 집계창과 다르다.

2026-11-09 재점검에서 개인 테스트 13개(v1 7개·S1 v2 2개·S5 v2 4개)가 통과했다. 운영 종료 경계·미래 정답 값/결측 독립성·물질수지·결측 그룹 보존을 확인했다. S1 v3의 18개 모델 지표·1,764개 그룹 성능 행과 S5 v2의 20개 모델 지표·2,000개 그룹 성능 행·72개 제어 추적도 저장된 근거에서 다시 계산해 일치했다. 학생·관리자 화면과 S1 v2의 6개 가상 상황을 자동 확인했고, v2의 추천 카드와 전체 비교 표는 같은 현재 점수 기준으로 정렬한다. 기존 동결 모델은 유지했다. 실제 캡처·짝 확인·설비 검증은 별도다.
