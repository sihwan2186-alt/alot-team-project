# 김시환 개인 조건에 따른 S1 S5 재설계

> 2026-11-04 완료 상태: 아래는 최초 설계 기록이다. S1·S5 데이터 분리, 학습·검증·시험, 동일 조건 제어 비교, 미래 정답 없는 화면 입력, 결과 내보내기와 화면 검증을 완료했다. 최신 실행법·수치·제약은 README.md와 results를 기준으로 한다. 선호 조건은 사용자 답변에 따라 기존 설계값을 유지한다. 실제 선호 기록과 유형 0 고장 원문 정의는 미확보 상태다. 보고서 최종본은 04_보고서/평가반영_20261103/최종수정본이다.

사용자 최신 요청: 모든 데이터를 같은 방식으로 학습하지 말고 김시환 본인의 조건과 모델별 목적에 맞게 데이터·학습·시뮬레이션을 하나씩 점검하고 구현한다. 이전 평가 반영 보고서 작업도 이어가되, 새 학습의 의미와 결과를 반영한 뒤 최종 확정한다.

확인 조건: 학번 2022451032, p=2, q=3, 시작 10:00, 개인 CO₂ 켜기 890ppm·해제 850ppm, 집계/예측 창 8분. 담당 S1 및 S5 공동. 대상은 선문대 스터디룸 목록 63실. q mod 3=0의 계산은 알지만 구체적 결함 유형의 원문 정의는 아직 없다.

사용자가 비동기 질문에 ‘기존 설계값 유지’로 명시 답변함: 목표 온도 23℃·습도 50%, 조도 300lux 이상, 소음 45dB(A) 이하, CO₂ 890ppm 미만. 이는 설계 선호이며 실제 이용자 평가 정답은 없다. 기존 가중치 noise .35, crowding .20, co2 .20, temp .10, humidity .10, light .05를 명시해 임시 점수로 사용한다.

데이터 계획: 공통시뮬레이터 data/runs/v02-full-30d의 실행 inputs 스냅샷을 사용한다. raw 센서에서 필요한 열·시간만 읽는다. S1은 10:00부터 운영 종료 전까지 8분 집계를 직접 만들어 창 종료 뒤 사용하고 소음은 에너지 기반 Leq로 집계한다. S5는 분 관측·현재 시설 상태·가상 공간 프로필만 쓴다. 밤·다른 담당 시나리오용 에너지/예약/정답 파일을 자동 조인하지 않는다. 0과 결측을 구분한다.

학습 계획: train 9/1~21, validation 22~25, test 26~30. 시간 무작위 분할 금지. 미래 8분 목표가 분할이나 운영 종료 경계를 넘으면 제외한다. 대체·표준화는 train에서만 fit. 검증 구간에서만 모델 선택 후 test는 한 번 고정 평가한다.

S1: 현재 8분 관측·과거 변화로 다음 8분의 설정 선호 점수를 예측하는 회귀. ‘현재 임계값 규칙’을 분류기로 외워 개인 만족도 학습이라고 쓰지 않는다. 실제 만족도 정답이 없어 설정 점수의 미래 예측임을 명시한다. 지속값·표준화 Ridge·HistGradientBoosting 회귀를 비교하며 검증 MAE로 선택한다. 현재 물리·결측·자리 조건을 별도 검사한 뒤 점수 순위를 제공한다.

S5: 현재 관측과 과거 8분 추세·현재 환기·재실·가상 volume/ACH로 t+8분 CO₂를 회귀 예측한다. 지속값·Ridge·HistGradientBoosting 비교. 미래 실제 인원·future facility·고장 플래그·truth·회복 종료 시각은 특징 금지. 예측은 로그 정책 아래의 미래 예측이며 제어 효과의 인과 추정이 아니다.

시뮬레이션 계획: 공통 엔진에 선택적 제어 callback을 추가하고 기본 동작을 보존한다. 공간 프로필·시각을 callback에 전달한다. 개인 임계값 890/850, 최소 가동시간은 제공 facility 규칙의 5분(8분 창과 구분). 예측 보조 정책과 개인 임계값 기준선을 동일 seed·예약·인원·고장·외기에서 비교한다. 모델은 고정 test 기간에만 사용하고 이전 기간은 동일 정책으로 워밍업한다. 환경·전력·상태·제어 요청·적용 성공을 함께 확인한다. 일부 고정 대표 공간으로 제한한 검증 범위를 명시하고 모든 학교 성능으로 일반화하지 않는다.

최초 계획 당시의 구현 전 기록(현재 상태 아님): 당시 문서·코드를 확인했고 사용자 선호 답변을 받았으나 새 개인 학습 코드는 작성하기 전이었다. 이후 개인 모델 구현과 검증을 완료했다. 기존 S1_S5/ml_model.py는 임의 가상 120실에서 규칙 정답을 학습한 CART이므로 그대로 개인 모델로 사용하지 않는다.

앞선 보고서 상태: 04_보고서/평가반영_20261103/수정본에 주차 6개+통합 1개가 있다. 구조 검증은 완료. 기존 Render.exe는 직접 실행하면 실패하지만 `dotnet .../Render.exe`로 호출하면 렌더링된다. Aspose 평가 모드는 긴 통합 문서를 잘라 W04 초반까지만 렌더링하므로, 통합 전체 검수는 적절한 단위로 나눠 읽기 전용 QA용 DOCX 조각을 렌더링하는 방식 등으로 해결해야 한다. 워터마크는 QA 출력에만 있고 원본 DOCX에 없다. Word COM Open은 멈춤 현상이 있어 재시도하지 않는다.
