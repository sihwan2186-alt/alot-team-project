## 수정 내용

1. **개인 모델 화면:** S1 v2의 추천 카드와 전체 공간 표가 서로 다른 기준으로 정렬되던 문제를 수정했다. 현재 점수를 표에 표시하고 양쪽을 같은 기준으로 정렬한다. 추론 입력에 미래 정답이나 임의 추가 열이 들어오지 않도록 데이터 계약의 정확한 허용 목록을 검사한다.
2. **W06 DB 적재:** 현재 13열 CSV와 일치하지 않는 capacity·motion·occupied_seats 참조를 제거했다. 현재 4개 테이블 스키마와 팀·건물·공간 키를 사용하고, 재적재를 한 트랜잭션으로 처리한다. `--source`·`--db`로 검증용 입력·DB를 지정할 수 있다. 합성 규칙 라벨의 의미도 DB 설명에 반영했다.
3. **W04 실행:** 이동된 교수 ZIP 경로를 수정했다. PowerShell 실행기 4개는 루트 Windows 가상환경과 Python 종료코드를 사용한다. 상대 SourceCsv는 작업 폴더를 바꾸기 전에 해석한다. W07 및 주차별 안내의 이전 환경·경로도 교정했다.
4. **공통 시뮬레이터:** 삭제된 심볼릭 링크에 의존하던 smoke·inspect 스크립트의 실행 경로와 프로젝트 루트 pytest import 경로를 수정했다. 예제 JSON은 UTF-8을 명시한다. 없는 폴더나 빈 폴더를 재현성 성공으로 판정하지 않으며, 잘못된 room_id는 실행 폴더 생성 전에 거부한다. Windows 실행법과 v0.2의 온도·전력 연결 설명을 갱신했다.
5. **현재 안내:** 루트 README·자료 찾기 HTML·보고서 안내에 최근 S1 v3·S5 v2 비교 결과를 연결했다. 기본 앱 v1, 학생 상황별 화면 S1 v2, 별도 분석 S1 v3·S5 v2를 구분한다. 기존 보고서의 v1 수치를 새 시험 수치로 혼합하지 않는다.
6. **보고서 대조:** 최종 DOCX 7개의 수치·수행 주체·유형 0 미확인 표기를 저장된 검증자료와 대조했다. 통합 부록의 W04 미실행 문구와 W07 실습일은 시점이 모호해 평가 반영 README에 해석과 본인 확인 사항을 추가했다. 기존 DOCX 본문·그림·배치는 보존했다. 배포 ZIP의 README도 현재 안내와 동기화했다.
7. **검사 도구:** `check_current_state.py`의 기본 출력을 실행 시각별 폴더로 바꿔 과거 11월 4일 기록을 덮지 않게 했다. 주요 실험 안내까지 링크 검사에 포함하고 PDF 본문 추출 여부는 실제 검사 방식에서 계산한다.

## 검증 결과

- 개인 모델 13개, 기존 S1_S5 프로토타입 24개, 공통 시뮬레이터 서로 다른 테스트 52개가 통과했다(합계 89개). 공통은 전체 50개 통과 후 추가한 2개를 포함한 관련 11개를 검사한 결과이며, 최종 52개를 한 번에 다시 실행한 수치는 아니다.
- S1 v2의 6개 상황에서 표 정렬·상위 카드 일치, 개인 학생/관리자 역할 왕복과 4실 표시, 동결 모델 해시 불변을 확인했다.
- S1 v3의 18모델·1,764개 세부 성능 행, S5 v2의 20모델·2,000개 세부 행·72개 제어 추적을 저장된 자료에서 재계산해 일치를 확인했다. 재학습·새 데이터 생성은 하지 않았다.
- W06 임시 DB 두 번 적재에서 64공간·6,144관측·106이벤트·106권고, 외래키 위반 0개를 확인했다. 의도적인 INSERT 실패 시 기존 DB 내용 보존도 확인했다. 기존 CSV·DB는 변경하지 않았다.
- W03 계산·경계·원본 불변, W04 임시 결과 192행/28행/24행/4행/96행, W07 손계산·6,144행 입력 계약을 확인했다. W09 임시 사본에서 학습 148행·시험 38행·MAE 0.0026을 확인했고 누수 예제의 의도된 assertion 실패도 확인했다. 이 결과는 이전 실행 결과를 갱신한 것이 아니다.
- W10 학생→관리자→공간 변경→학생 전환에서 상태 유지·무예외·입력 해시 불변을 확인했다. 현재 PowerShell 실행기 5개 구문 검사도 통과했다.
- 전체 Python 256개 구문 검사, 주요 안내 상대 링크 44개, v1 모델 해시·평가값, DOCX 7개 존재 확인이 통과했다. 최종 결과는 `current_state_checks.json`에 있다.
- 최종 DOCX 7개 해시는 기존 구조 검증 기록과 일치했고, ZIP 안 사본·README 동기화·CRC도 확인했다(`delivery_check.json`). 1,275개 비어 있지 않은 본문·표 문단에서 v1 수치와 수행 주체를 대조했다.

## 남은 확인과 검토 한계

PDF 추출·렌더링 도구(pypdf·Poppler)가 없고 pypdf 설치에서도 배포 패키지를 찾지 못해 이번에 PDF 본문을 새로 추출하지 못했다. DOCX 최종 페이지 배치와 모든 이미지도 새로 시각 검수하지 않았다. 기존 렌더·시각 검수 기록은 보존했다. Ruff도 설치되어 있지 않아 실행하지 못했다.

유형 0 고장 원문 정의, 본인 실행 캡처·실제 수행일·짝 확인, Word에서 최종 제출 배치 확인은 여전히 필요하다. 통합 부록의 2026.10.13을 본인 수행일 증거로 사용하지 않는다. 보관용 build_exam.py의 정규식 invalid escape 경고는 현재 실행 경로 밖의 과거 기록으로 남아 있으며 Python 문법 오류는 아니다.

파일 이동·삭제·Git 커밋·제출·외부 업로드, 기존 30일 데이터 재생성, 모델 교체는 수행하지 않았다. Git에 이미 있던 대규모 이동·삭제·스테이징 상태는 유지했다.
