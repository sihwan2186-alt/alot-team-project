# S1 학생용 데이터 적합성

2026-11-04. 동결된 정답 없는 시험 입력 25,363행·63실·405시점을 분석했다. 행은 공간×시각이다. 아래 비율은 학생 만족률·실제 시설 운영률이 아니라 합성 입력의 설계 조건 통과율이다. 화면에 도달하기 전 제외된 원천 자료까지 결측이 없다는 의미는 아니다. 기준·가중치·모델은 변경하지 않았다.

## 종류별 선택

| 종류 | 학생에게 답하는 질문 | 권장 활용 | 현재 자료의 한계 |
|---|---|---|---|
| 공간 식별·운영시간 | 어디이며 이용할 시각인가? | 공간명·건물·기준시각·운영시간을 선택/확인 정보로 사용 | 현재 운영 여부·예약 가능 여부를 보장하지 않음 |
| 정원·재실·여유좌석 | 앉을 자리가 있는가? | 필수 후보 조건. 좌석수와 혼잡 정도를 함께 표시 | 정원과 재실 모두 합성, 실제 이용 가능 좌석 아님 |
| 소음 Leq | 조용히 공부할 수 있는가? | 학생 비교의 주요 환경 정보. 8분 Leq와 조건 충족 여부 | 합성 소음, 개인별 선호·실제 집중도와의 관계 미검증 |
| CO₂ | 환기 상태를 비교할 수 있는가? | 설정 기준 890ppm 미만을 후보 검사에 유지하고 수치 표시 | 공식 안전 기준으로 해석 불가. 환기·공기질 전체를 대표하지 않음 |
| 온도 | 선호 온도에 가까운가? | 20~26℃ 범위와 목표23℃ 대비 차이를 구분 | 실제 만족도 정답이 없음 |
| 조도 | 공부할 밝기 조건을 만족하는가? | 현재 300lux 조건과 부족 여부 표시 | 빈 방의 조명이 꺼진 경우와 이용 중 어두운 경우를 구분할 자료 필요 |
| 습도 | 쾌적 조건을 만족하는가? | 반드시 관측값을 보존·표시. 데이터 가정을 먼저 점검 | 현재 분포가 40~60% 설계 범위와 거의 겹치지 않음 |
| 과거 변화·시각·요일·결측비 | 잠시 뒤 환경을 예측할 수 있는가? | 모델 내부 특징 및 신뢰도 설명에 사용 | 학생의 첫 화면에 원시 열을 모두 보여 줄 필요 없음 |
| 예측 점수 | 조건을 통과한 공간 중 무엇을 먼저 볼까? | 현재 후보 검사 후 보조 정렬, 8분 뒤 설정 환경 점수로 표시 | 실제 만족도·예약 확률 아님. 모든 미래 조건 충족을 보장하지 않음 |
| 실제 선택·만족도·좌석/예약·이동시간 | 학생이 실제로 갈 수 있고 선호하는가? | 향후 학생 추천 검증과 개인화의 우선 확보 자료 | 현재 확보되지 않았거나 검증되지 않음. 추정으로 채우면 안 됨 |

## 실제 분포 비교

| 데이터 | 중앙값 | 현재 조건 통과율 | 판단 |
|---|---:|---:|---|
| 여유좌석 | 6석 | 97.06% (1석 이상) | 후보 선택에 유용하나 실측/예약 연계 필요 |
| 온도 | 24.95℃ | 96.63% (20~26℃) | 현재 데이터에 비교적 적합 |
| 소음 | 40.49dB(A) | 76.78% (45 이하) | 공간 간 비교 정보로 사용 가능 |
| CO₂ | 830.88ppm | 66.78% (890 미만) | 후보 판정 및 비교에 사용 가능 |
| 조도 | 449.38lux | 68.86% (300 이상) | 재실·점등 상태의 맥락을 함께 확인할 필요 |
| 습도 | 67.83% | 0.16% (40~60%) | 추천 후보 부족의 주된 제약 |

현재 입력 표의 온도·습도·CO₂·소음·조도·좌석 값에는 결측이 없다. 과거 변화 특징에는 312~328개의 결측이 있다. 관측 시작·센서 결측 등으로 과거 차이를 만들 수 없는 경우이며, 학생 화면에서 0으로 바꾸면 안 된다. 모델의 결측 처리와 현재 후보 조건 검사를 구분한다.

모든 조건을 동시에 통과한 것은 12행·6시점이다. 원인 진단으로 습도 조건만 제외하고 나머지를 유지하면 7,899행·405시점에 후보가 생긴다. 다른 조건 하나만 제외할 때는 6~11시점이다. **습도 조건과 생성 데이터 분포의 불일치가 가장 큰 병목임을 보여 주며, 습도를 삭제해도 된다는 검증은 아니다.** 실제 만족도, 학습용 검증 구간 평가 없이 시험 구간 결과만 보고 정책을 바꾸면 안 된다.

## 학생용으로 적합한 구성

현재 자료에서 사용할 기본 묶음은 **공간·시각 + 여유좌석 + 소음 + CO₂ + 온도 + 조도 + 습도**다. 후보 자격은 기존 모든 조건으로 검사하고, 조건 통과 공간 안에서만 미래 환경 점수를 보조 정렬에 사용한다. 공간별 값을 나열하는 데 그치지 않고 '현재 조건 충족/어떤 항목 확인 필요'를 함께 표시하는 방식이 학생 판단에 적합하다.

메인 화면에는 공간명·현재 조건 충족 여부·좌석·소음·CO₂·주요 제외 이유를 우선 배치하고, 온습도·조도 세부값·예측 방법·전체 비교표는 추가 확인으로 제공할 수 있다. 이는 정보 배치 제안이며 어떤 환경 항목을 평가에서 삭제하라는 뜻은 아니다.

현재 모델은 김시환의 고정 설계 선호를 사용하는 합성 데이터 시연으로는 적합하다. 학생 전체를 대상으로 한 실제 추천 서비스로는 검증이 부족하다. 필요한 다음 단계는 (1) 합성 습도·외기·제습 가정 점검 (2) 실제 좌석·운영/예약 상태 확보 (3) 학생별 선택·이용 목적·만족도 수집 (4) 새 버전의 검증 구간에서 가중치·조건·특징 묶음 비교다.

학습 특징은 각각 학생 선택에 설명 가능한 역할이 있지만, 이번 기술통계만으로 특정 특징이 예측 정확도에 반드시 필요하다고 입증한 것은 아니다. 특징 제거 비교·개인화 성능 평가는 별도 수행이 필요하다.
